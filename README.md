## 📱 APK Ансамбля (план)

После Эхад day планируем превратить веб-морду в безопасное мобильное приложение — как замену официальным клиентам VK, Telegram, YouTube.

### Архитектура безопасности

| Компонент | Мера защиты |
|-----------|-------------|
| **PWA / APK** | Подпись собственным ключом, распространение через браузер (без сомнительных APK-файлов) |
| **Сеть (WebView)** | Certificate Pinning (привязка сертификата сервера Render) |
| **Веб-морда** | HTTPS, авторизация по ADMIN_PASSWORD |

### Почему это безопасно

1. **Подпись** — приложение нельзя подделать
2. **Certificate Pinning** — защита от перехвата трафика и атак «человек посередине»
3. **Официальный путь** — установка через браузер (WebAPK), а не скачивание APK с левого сайта

### Что даст

- Телефон без VK, Telegram, YouTube
- Вместо них — **Ансамбль**
- Управление ботом, лента сообщений, YouTube-прокси — всё в одном приложении

> *«Не замена соцсетям. Замена их клеткам.»*
