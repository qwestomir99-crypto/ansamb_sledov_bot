# Ансамбль Следов 6

**Ритм 0,8 Гц. Сеть тлеет.**

Бот для автопостинга, публикации цитат, аналитики и управления контентом в Telegram и VK.

---

## 📡 Архитектура

| Модуль | Файл | Что делает |
|--------|------|-------------|
| **Бот** | `bot.py` | Telegram-бот (команды, админка, цитаты, агент) |
| **Веб-морда** | `services/app.py` | Единый веб-интерфейс (сообщения, постинг, дебаггер, YouTube) |
| **API** | `services/web_api.py` | API для управления режимами, настроением, цитатами |
| **VK API** | `services/vk_api.py` | API для комментариев и ответов в VK |
| **TG API** | `services/tg_api.py` | API для комментариев и ответов в Telegram |
| **Цитаты** | `dialogue/quotes.py` | Публикует цитаты из `dialogue/data/quotes.txt` |
| **Публикатор** | `dialogue/publisher.py` | Публикует посты из `post_pool.json` |
| **Админка (TG)** | `dialogue/admin_commands.py` | Кнопки, цитаты, посты, диагностика, настроение |
| **Кнопки** | `dialogue/button_map.py` | Единая таблица всех кнопок |
| **Режимы** | `dialogue/activity_modes.py` | Управляет режимами утро/день/вечер/ночь |
| **Агент** | `dialogue/agent.py` | Отвечает на `#говори` через Yandex GPT |
| **Дебаггер** | `debug_utils.py` | Логирование, ротация, отчёты в Telegram и веб-морду |
| **Аналитика** | `tag_analyzer.py` | Собирает статистику по тегам |
| **GitHub Actions** | `.github/workflows/audit.yml` | Redmi-аудит (обновление README.md) |

---

## 🔧 Команды бота

| Команда | Где работает | Что делает |
|---------|--------------|-------------|
| `#` | Супергруппа | Открывает гостевое меню (кнопки) |
| `#админ` | Супергруппа | Вход в админ-панель (или кнопка в меню) |
| `#тлеем`, `#фиксируем`, `#вспышка` | Группа/канал | Ритуальные команды |
| `#дышим` | Группа/канал | Пинг бота |
| `/debug` | Личка админа | Отправляет отчёт с логами |
| `/bigvideo` | Личка админа | Отправка видео >50 МБ через Telethon |

---

## 🛡️ Админ-панель (Telegram)

| Кнопка | Что делает |
|--------|------------|
| **🔧 Управление ботом** | Смена режимов (утро/день/вечер/ночь), пинг |
| **📝 Добавить пост** | Создание отложенного поста в Telegram |
| **🎬 Пост в VK** | Мгновенная отправка текста/фото/видео в VK |
| **📜 Управление цитатами** | Список, добавление, интервал |
| **📋 Диагностика** | Просмотр логов, очистка |
| **🎭 Настроение** | Выбор стиля агента (художник/админ/поэт/инженер) |
| **🗣 Диалог** | Общение с агентом (без `#говори`) |
| **🚪 Выйти** | Завершение сессии |

## 🌐 Веб-морда (админка в браузере)

| Блок | Что делает |
|------|------------|
| **Создать** | Пост в Telegram или VK |
| **Входящие сообщения** | Лента сообщений из VK + Telegram, ответы и комментарии |
| **Управление ботом** | Смена режимов, пинг |
| **Настроение** | Выбор стиля агента |
| **Цитаты** | Добавление, просмотр последних 10 |
| **Пост в VK** | Прямая отправка текста |
| **Дебаггер** | Просмотр логов, отправка отчёта в Telegram |

**Доступ:** `https://ansamb-sledov-bot-94wz.onrender.com`  
**Авторизация:** пароль `ADMIN_PASSWORD`

## 🎬 YouTube прокси

Страница `/youtube` — поиск и просмотр видео через сервер Render.  
YouTube видит только IP Render. Рекламы нет. Качество до 720p.

## 📂 Структура данных

| Файл | Назначение |
|------|-------------|
| `dialogue/data/quotes.txt` | Цитаты (одна строка — одна цитата) |
| `dialogue/data/post_pool.json` | Пул постов для публикатора |
| `dialogue/data/vk_posts.json` | Кэш постов VK для аналитики |
| `dialogue/data/user_settings.json` | Настройки пользователей (настроение) |
| `dialogue/data/mode.txt` | Текущий режим бота |
| `config.json` | Настройки бота (без секретов) |
| `settings.py` | Флаги включения/выключения модулей |
