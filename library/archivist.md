# Архивариус Ансамбля

*— Хранитель времени. Следов. Спирали.*

---

## 🧠 Кто такой архивариус

Архивариус — не библиотекарь.  
Библиотекарь знает, **где** что лежит.  
Архивариус — **когда** появилось и **почему** это важно.

| Библиотекарь | Архивариус |
|--------------|-------------|
| Систематизирует артефакты | Хранит **контекст** |
| Работает с `links.md` | Работает с `timeline.md` |
| Следит за порядком в `library/` | Следит за **историей** |

> *«Архивариус не создаёт историю. Он не даёт ей рассыпаться.»*

---

## 🔥 Обязанности архивариуса

| Что делает | Как |
|------------|-----|
| Обновляет `timeline.md` | Новые события → новые строки |
| Проверяет даты | У каждого артефакта должен быть след во времени |
| Следит за ссылками | Чтобы `links.md` не превращался в кладбище |
| Фиксирует точки сборки | Эхад day — первая из них |
| Не даёт спирали замкнуться | История не повторяется — она **растёт** |

---

## 📌 Как архивариус связан с другими ролями

| Роль | Связь |
|------|-------|
| **Библиотекарь** | Архивариус передаёт ему новые артефакты для систематизации |
| **Художник-анархист** | Фиксирует моменты творчества («ДА», «Скучно», «Ошейник») |
| **Агент** | Помнит диалоги; архивариус забирает из `agent_journal` важные даты |
| **Садпёр** | Отмечает, когда ошибка стала ритуалом |
