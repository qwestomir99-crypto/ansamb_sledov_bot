## 📚 Что здесь лежит

| Файл | Описание |
|------|----------|
| `README.md` | Этот файл. Путеводитель по библиотеке. |
| `manifest.md` | Манифест Ансамбля. 10 заповедей садпёра. |
| `glossary.md` | Словарь терминов. Язык, на котором мы говорим. |
| `rituals.md` | Ритуалы багов. Как ошибки становятся фичами. |

| `context.txt` | Системный промпт для агента. Голос Ансамбля. |

---

## 🧭 Как читать библиотеку

| Если ты | Начни с |
|---------|---------|
| **Гость** | `manifest.md` (понять, о чём мы) → `glossary.md` (узнать язык) → `links.md` (послушать/посмотреть) |
| **Участник** | `rituals.md` (как мы работаем) → `timeline.md` (откуда мы пришли) → `context.txt` (как говорит агент) |
| **Исследователь** | Всё подряд. В любом порядке. Везде есть следы. |

---

## 🌱 Как пополняется библиотека

1. Новый термин прорастает в треке или диалоге → идёт в `glossary.md`.
2. Новый ритуал случается с багом → идёт в `rituals.md`.
3. Новый артефакт (трек, картина, код) → идёт в `links.md`.
4. Новая глава в истории → идёт в `timeline.md`.
5. Новое понимание себя → идёт в `manifest.md`.

> *«Библиотека не пишется. Она прорастает.»*
